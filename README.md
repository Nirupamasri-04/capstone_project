# Capstone Project

This repository contains three modules completed as part of the capstone project:

1. Data Pipeline – scrape, clean, enrich, store, and query book catalog data.
2.  Analytics – perform EDA and machine learning analysis on the Titanic dataset.
3. Support Assistant – build a local Zepto policy assistant using embeddings, ChromaDB, LangGraph, FastAPI, and Docker.
